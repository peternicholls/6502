# Completed evidence

This directory contains verified historical evidence. It records what passed;
it does not define current architecture, select future work or reopen completed
requirements.

The ledgers were moved byte-for-byte. Their relative links record the original
layout and some no longer resolve from this directory; this index supplies the
current navigation without rewriting historical evidence.

- [C0 baseline ledger](CORE_BASELINE.md) preserves the pre-C0 observation,
  approved references and C0 exit evidence.
- [Status through C2](STATUS-through-C2-2026-07-19.md) preserves the detailed C0,
  C1 and C2 completion records as they stood on 2026-07-19.
- [Completed Spec Kit runs](../../specs/completed/) preserve the specifications,
  plans, tasks, research and contracts for C0-C2.

For current claims use [STATUS.md](../STATUS.md). For future direction use the
[Machine delivery plan](../product/MACHINE_DELIVERY_PLAN.md).
