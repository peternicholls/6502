# Primary references and test material

- MOS Technology, *MCS6500 Microcomputer Family Programming Manual*:
  <https://mirrors.apple2.org.za/ftp.apple.asimov.net/documentation/hardware/processors/MCS6500%20Family%20Programming%20Manual.pdf>
- *BBC Microcomputer Advanced User Guide* (OS 1.20 / issue 4 hardware):
  <https://stardot.org.uk/mirrors/www.bbcdocs.com/filebase/essentials/BBC%20Microcomputer%20Advanced%20User%20Guide.pdf>
- Intel, *8271 Programmable Floppy Disk Controller* data sheet:
  <https://www.theoddys.com/acorn/semiconductor_datasheets/D8271.pdf>
- Klaus Dormann, 6502/65C02 functional tests (GPL-3.0 test material):
  <https://github.com/Klaus2m5/6502_65C02_functional_tests>
- Bruce Clark decimal test, distributed as public-domain source in the Klaus
  repository: <https://github.com/Klaus2m5/6502_65C02_functional_tests/blob/master/6502_decimal_test.a65>
- Visual6502 decimal-mode observations and difficult vectors:
  <https://www.nesdev.org/wiki/Visual6502wiki/6502DecimalMode>
- Thomas Harte, Unified Emulator Format draft specification:
  <https://electrem.emuunlim.com/UEFSpecs.htm>

The earlier project began from discussion of Dave Poo's educational C++ core.
This implementation is new and does not copy that source:
<https://github.com/davepoo/6502Emulator>.

`jsbeeb` remains an architectural/UX comparison only. Its GPL source is not
incorporated into this MIT project.
