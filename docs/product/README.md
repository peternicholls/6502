# Product documentation strand

This strand describes the wider Beeb6502 application: the people it serves,
the Machine, Media and Editor experiences, and the order in which those
experiences should mature.

- [Vision](VISION.md) defines durable product intent and success outcomes.
- [Roadmap](ROADMAP.md) sequences user-facing capability horizons.
- [Legacy decision register](LEGACY_DECISIONS.md) interprets design material
  imported from the abandoned product implementation.

These documents may create requirements for the emulator, but they do not
define its internal architecture or claim that a capability is implemented.
The emulator strand owns those concerns:

- [Core roadmap](../CORE_ROADMAP.md)
- [Implementation status](../STATUS.md)
- [Core architecture](../ARCHITECTURE.md)
- [Technical references](../REFERENCES.md)

When the strands interact, the product roadmap states the user outcome and the
core roadmap states the enabling technical capability. `STATUS.md` remains the
only authority for what has actually been verified.
